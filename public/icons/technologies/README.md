Project stack badges use local SVG/PNG assets registered in `src/constants/technology.ts`. Project data accepts only registered technology names, so new stack entries cannot silently fall back to a generic icon.

Sources:
- Simple Icons: LangChain, OpenRouter, WebRTC, Socket.IO, shadcn/ui, PyTorch, FastAPI, Hugging Face, NumPy, Streamlit, Prisma, Cheerio, and JSON. Twilio comes from release 15.0.0. https://github.com/simple-icons/simple-icons
- Devicon: Playwright, Matplotlib, and SQL Server. https://github.com/devicons/devicon
- Tabler Icons: React, Next.js, Tailwind, TypeScript, JavaScript, HTML, CSS, Node.js, Redux, Python, MongoDB, MySQL, Docker, Git, GitHub, Framer, Go, Swift, Django, OpenAI, Firebase, AWS, and React Native. https://github.com/tabler/tabler-icons
- Vapi: https://vapi.ai/icon.svg
- React Flow: https://reactflow.dev/icon.svg
- HTTPX: https://www.python-httpx.org/assets/images/favicon.png
- Pinecone: the logo embedded in https://www.pinecone.io/ (cropped to its symbol).

Beautiful Soup, PyPDF, Pillow, BERTScore, Gymnasium, PyBullet, pyodbc, JSDOM, Verilog, Vivado, Express, Payload, and A/B Testing use locally drawn text marks. These are identification badges, not claims of official brand artwork. No generic code, globe, database, or other placeholder symbols are used.

Monochrome/dark marks invert in dark mode for contrast; other marks retain their colors.
